# 要件定義

## 機能要件

### 画像表示・スワイプ機能

- 画像プール（80枚）から10枚（1特性2枚 × 5特性）を選出して表示
- 1枚ずつ画像を表示（カード形式）
- 左右スワイプで「Me / Not Me」を選択（メイン操作）
- ボタンタップでも選択可能（補助操作）
- スワイプアニメーションの実装
- 進捗インジケーター（残り枚数表示）

### チェック機能

- スワイプ結果の集計
- ローカル計算でBig Fiveスコア算出
- 8タイプのパーソナリティ判定

### 結果画面

- パーソナリティタイプ表示（8タイプ）
- タイプ別キャラクター画像・アニメーション（Headspace風フラットデザイン）
- Big Five スコアのレーダーチャート表示
- 各特性のスコアカード（リッチなプログレスバー）
- アドバイス（こんな一面も）
- あるあるシチュエーション（5個→3個ランダム表示）
- おすすめ（過ごし方・曲・本、3セット→1セットランダム表示）
- 「今のキミ」メッセージ（結果は今の気分の反映＝また変わる、と伝える）

### シェア機能

- X（Twitter）シェアボタン
- OGP対応（タイプ別OG画像、静的配信）
- シェアURLにタイプ情報を含める（`/result/[type]`）
- 友達比較導線（シェアリンクから来た訪問者 → `/?friend={typeId}` でホーム誘導、ホワイトリスト検証）

### その他

- レスポンシブデザイン（モバイルファースト）
- 日本語/英語切り替え対応
- Dev Mode（`?dev=1` でタイプ切替ドロップダウン表示）
- SEO基盤（sitemap.xml、JSON-LD）
- OGP画像（タイプ別静的PNG、1200×630）

## 非機能要件

### パフォーマンス

- 画像の遅延読み込み（次の画像を先読み）
- API応答時間：目標3秒以内

### アクセシビリティ

- キーボード操作対応（←→キーで選択）
- ボタン操作対応（マウス/タッチ）
- スクリーンリーダー対応（任意）

### セキュリティ


## 画面一覧

| 画面名 | 説明 |
|:--|:--|
| トップページ | アプリ説明、スタートボタン |
| スワイプ画面 | 画像表示、スワイプ操作 |
| 結果画面 | チェック結果表示 |

## ユーザーフロー

```
[トップページ] → [スワイプ画面（10枚）] → [結果画面]
```

## UI仕様（スワイプ画面）

```
┌─────────────────────┐
│                     │
│       [画像]        │  ← スワイプ可能エリア
│                     │
├─────────────────────┤
│ [Not Me]    [Me]    │  ← ボタン（補助）
│       3 / 10        │  ← 進捗表示
└─────────────────────┘
```

### 操作方法

| 操作 | 対象 | アクション |
|:--|:--|:--|
| 左スワイプ | スマホ | Not Me |
| 右スワイプ | スマホ | Me |
| ボタンタップ | 全デバイス | Not Me / Me |
| ←キー | PC | Not Me |
| →キー | PC | Me |
