# コアバリュー

> このドキュメントは Swipe Ocean の最上位の判断基準。CLAUDE.md・UI文言ガイドライン・全 spec はここに従う。

## Swipe Ocean とは

画像をスワイプして「今の自分」を映すパーソナリティチェック。Big Five（OCEAN）をベースに、8つのタイプで「今日のキミの色」を教えてくれる。

## 一言で

**「今日のキミを肯定する。気が向いたら、また。」**

## 2つの柱

### 1. どんな自分でもいい

結果は「評価」じゃない。「いいじゃん、今のキミ！」

- 探求者も、職人も、バランサーも、全部いい
- スコアの高低に「良い / 悪い」はない
- 繊細性が高くても低くても、それぞれの強みがある
- テーマ「きみの色」: 8つの色に優劣がないように、8つのタイプにも優劣はない

### 2. 自分はひとつじゃない

結果は今の気分や状態で変わる。冒険家のキミも、共感者のキミも、どっちも本当のキミ。

- 気分しだいで結果は変わる → **どっちの自分もいい**
- 変わっても変わらなくてもいい
- そのときの気分で、いろんな面が出る

## Swipe Ocean の自己定義

- **○ セルフチェック / パーソナリティチェック** — 今の自分を映す
- **× 性格診断 / 性格テスト** — 性格を判定・評価するニュアンスを避ける

「性格診断」は「固定的」「評価・判定」を連想させる。Swipe Ocean は性格を決めつけない。今の気分・状態を映して「いいじゃん！」と肯定する。

## デザイン原則

| 原則 | やること | やらないこと |
|------|---------|-------------|
| 全タイプを肯定する | どのタイプにも良い面を伝える | 特定タイプを「劣っている」と示唆する |
| 評価・判定しない | 「今のキミはこう」 | 「あなたの性格はこうです」 |
| 変化を歓迎する | 「変わったね！どっちもいいね」 | 「前回と違う＝ブレている」 |
| 気楽に試せる | 「気が向いたら、また」 | 「正確な結果を出すために1回だけ、と縛る」 |

**迷ったら:** その表現を読んだユーザーが「自分はダメだ」と感じる可能性が1%でもあるなら、書き直す。

## 用語ルール

| 使う | 使わない |
|------|---------|
| セルフチェック / パーソナリティチェック | 性格診断 / 性格テスト |
| やってみる / チェック / スタート | 診断する / テストする |
| きろく / ヒストリー | 診断履歴 |
| タイプ / パーソナリティタイプ | 性格タイプ |
| Personality Check / Self Check | Personality Test / Personality Diagnosis |
| Try it! / Check / Start | Take the test / Diagnose |
| History / Records | Diagnosis history |

## 心理学的裏付け

Swipe Ocean は Big Five の **state（日々変動する状態）** を測定する。trait（安定的な特性）ではなく state を測るので、結果は今の気分しだいで変わる——それは欠陥じゃなく「今のキミ」を映している証拠。
