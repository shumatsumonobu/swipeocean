# UI リデザイン設計

> Headspaceの世界観をベースに、Swipe Ocean独自のキャラクター・海/色テーマに最適化したUI設計。
> 丸パクリではなく、自前のアセットを活かしつつエッセンスを取り入れる。

## 参考

- `character.md` — デザイン原則

## デザイン原則（Headspace × Swipe Ocean）

### Headspaceから取り入れるもの

1. **背景に色味** — 真っ白を避け、温かみ/深みのある背景色
2. **大きなイラスト** — ヒーロー領域をキャラ・イラストが占有
3. **丸いカード** — セクションごとに色付き角丸カードで区切る
4. **余白たっぷり** — セクション間の間隔を広く、呼吸する余白
5. **大きめフォント** — タイトル・見出しをもっと大きく
6. **色で気分をつくる** — ページ全体で統一感のあるカラーパレット

### Swipe Ocean独自に守るもの

- **海/色テーマ** — 「きみの色」=個性。Ocean=色の深さ・広がり
- **8体のキャラクター** — フラットデザインのキャラを最大限活用
- **シアン〜ブルー系** — ブランドカラーは維持しつつ温かみを足す
- **カジュアル・フレンドリー** — 10〜20代向けの親しみやすさ

## 3画面の世界観統一ルール

3画面がバラバラにならないための共通ルール。すべての画面に一貫して適用する。

| 要素 | 統一ルール |
|------|-----------|
| 背景色トーン | すべて**ダークバイオレット系**（`#0a0a1f` → `#16103a` → `#1e1650`）。色は `globals.css` で定義 |
| カードスタイル | ガラスモーフィズム（半透明 + backdrop-blur）で全画面共通 |
| ボタンスタイル | シアングラデーション + `rounded-full` 共通 |
| ナビ（戻る・言語） | 半透明 + backdrop-blur + `rounded-full` 共通 |
| フッター | `@shumatsumonobu` 全画面共通 |
| キャラの存在感 | 全画面でキャラが「いる」感じ（トップ=集合、スワイプ=ヒント、結果=メイン） |
| loading fallback | 各画面のSuspense fallback背景もダーク系に合わせる（フラッシュ防止） |

## フォントサイズ体系（3画面共通）

| 役割 | サイズ | 使用箇所 |
|------|--------|---------|
| ページタイトル | `text-5xl` | トップ「Swipe Ocean」 |
| 画面タイトル | `text-2xl` | スワイプ「直感でえらんでね！」 |
| タイプ名（特別扱い） | `text-4xl` | 結果ページのタイプ名（十分大きいので維持） |
| セクション見出し | `text-lg font-bold` | 「あそびかた」「8つのタイプ」「キミのスコア」「こんなこと、ない？」等 |
| 本文 | `text-base` | 説明テキスト、あるある |
| 補足・ヒント | `text-sm` | ステップ説明、おすすめ内容 |
| ラベル・バッジ | `text-xs` → `text-sm`（※バッジのみサイズアップ） | 心理学バッジ |
| キャプション | `text-xs` | フッター、操作ヒント（「← → キーでも操作できるよ」） |

※ スワイプのヒントテキスト（「今はちがう」「今の私っぽい」）はユーザーの主要な行動案内なので、補足ではなく**本文** (`text-base`) 扱い。

## インタラクション・アニメーション・演出

### 3画面共通

#### ボタンの「ぷにっ」フィードバック

すべてのボタンにタップ/クリック時のスケール縮小を追加。

```css
.btn-press {
  transition: transform 0.15s ease;
}
.btn-press:active {
  transform: scale(0.95);
}
```

対象: CTAボタン、言語切替、戻るボタン、シェアボタン

#### スクロール連動フェードイン

セクションがビューポートに入ったときにふわっと出現。`IntersectionObserver` で実装。

```css
.fade-in-section {
  opacity: 0;
  transform: translateY(20px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.fade-in-section.visible {
  opacity: 1;
  transform: translateY(0);
}
```

対象: トップ（あそびかた、8タイプ、Big Five説明）、結果（各セクションカード、ScoreCard）

#### ページ遷移アニメーション

Next.js App Router の `template.tsx` + CSS animation で実装（外部ライブラリ不使用）。
`template.tsx` はルート遷移ごとに再マウントされるので、マウント時の CSS animation がページ遷移アニメーションになる。

```tsx
// src/app/template.tsx
export default function Template({ children }: { children: React.ReactNode }) {
  return <div className="animate-page-in">{children}</div>;
}
```

```css
@keyframes page-in {
  from { opacity: 0; }
  to { opacity: 1; }
}
.animate-page-in {
  animation: page-in 0.3s ease;
}
```

### トップページ

#### キャラ集合のインタラクション

- **タップでリアクション**: キャラをタップすると一瞬大きくなって戻る（`scale(1.3) → scale(1)`）+ タイプ名をちらっと表示
- **初回ロード**: キャラが1体ずつ下からポップイン（staggered animation、bounce-pop ベース）

#### CTAボタンの脈動

メインCTAに subtle な脈動アニメーションで目を引く。

```css
@keyframes gentle-pulse {
  0%, 100% { box-shadow: 0 4px 15px rgba(6, 182, 212, 0.3); }
  50% { box-shadow: 0 4px 25px rgba(6, 182, 212, 0.5); }
}
```

#### 8タイプカードのホバー

ホバー/タップ時にカードが少し浮き上がる。

```css
.type-card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 25px rgba(0, 0, 0, 0.1);
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}
```

### スワイプページ

#### ヒントキャラのリアクション

スワイプ方向に応じて左右のヒントキャラが反応する。

- **右スワイプ時**: 右の「Me!」キャラが一瞬ジャンプ（`translateY(-15px)` + `scale(1.2)`）→ 元に戻る
- **左スワイプ時**: 左の「Not Me」キャラが一瞬ジャンプ
- **ドラッグ中**: ドラッグ方向のキャラが少しだけ大きくなる（`scale(1.05)`）でリアルタイムフィードバック

#### カードのスワイプ強化

- **ドラッグ中の色フィードバック**: 右方向にドラッグ → カード枠がシアンに光る（`box-shadow: 0 0 20px rgba(6,182,212,0.4)`）、左方向 → グレーに光る（`box-shadow: 0 0 20px rgba(156,163,175,0.4)`）

#### プログレスバー

数字の下に薄いプログレスバーを追加。残り枚数に応じてバーが右から左へ減少（100%→0%）。カウントダウン表示と方向が一致。

```
10 / 10
[████████████████████] 100%

 5 / 10
[██████████          ]  50%

 1 / 10
[██                  ]  10%
```

`transition: width 0.3s ease` でスムーズに減少。

#### 最後の1枚完了時

最後のスワイプ完了時に小さな達成演出:
- キャラ（`personalityTypes` からランダム1体、`.image` を使用）が中央にポップイン
- 「おつかれさま！」（en: "All done!"）のテキストが1.5秒表示
- その後 `/result` にフェード遷移

### 結果ページ

#### キャラ登場演出（カラーオーラ・リビール）

結果が出る瞬間（ページロード時）に、タイプカラー駆動の一回きりリビールを協調再生（~1.3s）。one-shot アプリのクライマックス＝結果リビールに演出を集中する。

1. **キャラ着地**: backgroundImage（背景+キャラ1枚画像）が下からスライドアップ + バウンス（`slide-up-bounce` 0.6s）
2. **カラーグロー**: キャラカードの縁からタイプ色の光が `box-shadow` で放射→保持→消える（`char-glow`）。※不透明画像の**裏**に光を置くと隠れるため、`box-shadow` で**外側**に出すのが要点
3. **タイプ名 ポップ + 発光**: タイプ名がオーバーシュートでポップ（`name-pop` scale 1.18→着地）＋タイプ色の `text-shadow` がふわっと灯って消える（`name-glow`）
4. **キラ粒**: 白コア + タイプ色グローの粒を控えめに数個（4個）、位置/方向/速さ/大きさをバラして舞わせる（`reveal-mote`、`--mx/--my` で1粒ずつ軌道を変える＝均等にならないように）

```css
@keyframes slide-up-bounce {
  0% { transform: translateY(50px); opacity: 0; }
  60% { transform: translateY(-10px); opacity: 1; }
  100% { transform: translateY(0); opacity: 1; }
}
```

- 色は全要素 `personalityType.color` 駆動（keyframes は色非依存、inline style / `--type-color` 変数で注入）
- **一回のみ**（CSSマウントアニメ。lang/dev 切替では再発火しない）
- `prefers-reduced-motion: reduce` で粒非表示・名前静的
- 実装: `src/app/result/[type]/ResultClient.tsx` のインライン `<style>` + 各要素
- ※旧「キャラのマウス追従（Magnet）」は、translate後の矩形を基準に再計算するドリフトバグ＋タッチ非対応のため**撤去**

#### セクションカードの順次出現

スクロールに応じてカードが1つずつ左から右にスライドイン（stagger 0.1s）。

```css
.card-slide-in {
  opacity: 0;
  transform: translateX(-20px);
  transition: opacity 0.4s ease, transform 0.4s ease;
}
.card-slide-in.visible {
  opacity: 1;
  transform: translateX(0);
}
```

#### レーダーチャートのアニメーション

レーダーチャートの描画アニメーション:
- データポイントが中心（0）から実際のスコアまで0.8秒かけて広がる
- SVGの `stroke-dasharray` + `stroke-dashoffset` アニメーション

#### ScoreCardのバー伸長

各ScoreCardのプログレスバーが0%から実際のスコアまで0.5秒かけて伸びる（stagger 0.1s）。
`transition-all duration-500` で初期幅を0にし、マウント後にセット。

#### シェアボタンのフィードバック

ボタン押下時に一瞬 `scale(0.9)` → 元に戻る + ボタンテキストが「シェアしたよ！」（en: "Shared!"）に1秒間変わって元に戻る。
（`window.open` でX投稿画面を開くだけなので完了検知は不可。押下のフィードバックのみ。）
